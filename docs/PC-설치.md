# PC 옮기기 — 입찰 시스템을 새 폴더로

2026-08 에 입찰 시스템과 모집·신청 시스템을 **다른 저장소로 갈랐습니다.**
그래서 PC 에도 폴더가 두 개가 됩니다.

```
  ...\sraj          ← 모집·신청 (그대로 둡니다)
  ...\sraj-g2b      ← 입찰 (새로 만듭니다)
```

모아둔 원본(`data\g2b`)은 **반드시 옮겨야 합니다.** 없으면 처음부터 다시
수집해야 하는데, 나라장터 API 는 하루 호출 한도가 있어 1년치를 다시 채우는
데 여러 날이 걸립니다.

---

## 1. 새 폴더 만들기

1. 탐색기에서 지금 쓰는 **sraj 폴더**를 엽니다.
2. 위쪽 주소창을 클릭해 주소를 지우고 `cmd` 라고 친 뒤 엔터.
   → 그 폴더 위치에서 검은 창이 열립니다.
3. 아래 한 줄을 통째로 복사해 붙여넣고 엔터. (마우스 오른쪽 클릭이 붙여넣기입니다)

```
git clone https://github.com/srajjihun/sraj-g2b.git ..\sraj-g2b && xcopy /e /i /y "data\g2b" "..\sraj-g2b\data\g2b" && cd /d ..\sraj-g2b && node scripts\g2b\reclassify.mjs && node scripts\g2b\build-page.mjs && start "" g2b-live.html
```

이 한 줄이 하는 일 — 새 폴더를 내려받고, 모아둔 원본을 옮기고, 지금 키워드로
다시 분류해 화면을 만들어 띄웁니다. 나라장터를 부르지 않으므로 호출 한도와
무관합니다.

화면이 뜨면 성공입니다. 앞으로 **화면-새로고침.bat 은 새 폴더(sraj-g2b) 것**을
누르세요. 바탕화면에 바로가기를 만들어 두면 편합니다.

## 2. 자동 수집 등록

새 폴더의 **자동수집-등록.bat** 을 한 번 누르면 끝입니다.
매일 아침 7시에 창 없이 저절로 돕니다.

시각을 바꾸고 싶으면 그 폴더에서 검은 창을 열고 `schedule.bat 08:30` 처럼
시각을 붙여 실행하세요. 여러 번 눌러도 작업이 겹치지 않습니다(같은 이름을
덮어씁니다).

회사 PC 정책으로 등록이 막히면 화면에 손으로 등록하는 순서가 나옵니다.

옛 폴더의 기존 작업은 **그대로 둡니다.** 모집 담당이 그쪽에서 입찰 부분을
떼어내면 자동으로 모집만 돌게 됩니다.

## 3. 확인

다음 날 아침에 새 폴더의 `logs\g2b.log` 를 열어 마지막 줄에
`g2b collect end` 가 있으면 정상입니다.

## 4. 나중에 — 옛 폴더 정리

모집 담당이 옛 저장소에서 입찰 파일을 떼어낸 뒤에는, 옛 폴더에 남아 있는
`collect-g2b.bat` · `g2b.html` · `scripts\g2b\` · 각종 입찰용 .bat 이
저절로 사라집니다. 손으로 지울 필요는 없습니다.

옛 폴더의 `data\g2b` 는 1번에서 복사한 것이라 새 폴더에도 있습니다.
새 폴더가 며칠 정상으로 도는 것을 확인한 뒤에 지우세요.

## 자주 나는 문제

**`git`이 없다고 나옵니다**
→ https://git-scm.com 에서 설치한 뒤 검은 창을 새로 열고 다시 하세요.
   git 없이 하려면 https://github.com/srajjihun/sraj-g2b 에서
   초록색 **Code → Download ZIP** 으로 받아 `sraj-g2b` 폴더로 풀고,
   옛 폴더의 `data\g2b` 를 그 안에 통째로 복사한 뒤
   `화면-새로고침.bat` 을 누르면 됩니다(이 방식도 계속 쓸 수 있습니다).

**화면은 떴는데 공고가 하나도 없습니다**
→ `data\g2b` 복사가 안 된 것입니다. 옛 폴더의 `data\g2b` 폴더를 통째로
   새 폴더의 `data` 안에 넣고 `화면-새로고침.bat` 을 다시 누르세요.

**`G2B_SERVICE_KEY` 오류가 납니다**
→ 인증키는 Windows 사용자 환경 변수라 폴더를 옮겨도 그대로 있습니다.
   이 오류가 나면 `G2B-설치.bat` 을 한 번 눌러 다시 등록하세요.
